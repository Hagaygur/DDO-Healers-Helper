DDO HEALER'S HELPER 1.4.0

CHOOSE THE ARCHIVE MATCHING YOUR DUNGEON HELPER VERSION.
HealersHelper-X.Y.Z-source.zip is separate; do NOT import it into Dungeon Helper.

=== DUNGEON HELPER 4 (4.2.x, .NET 8 Windows) ===
1. Close DDO. Open Dungeon Helper Settings > Add plugin from zip file.
2. Select HealersHelper-X.Y.Z-dh4-plugin.zip (contains plugins/HealersHelper/VoK.HealersHelper.{dll,deps.json,metadata}).
3. If asked to overwrite the already-installed HealersHelper folder, choose Yes.
4. Fully exit Dungeon Helper from its tray icon, restart it, then launch DDO.

If DH 4 refuses the update or reports a file in use:
Fully close DDO and Dungeon Helper, extract plugins\HealersHelper\* into:
  %APPDATA%\Dungeon Helper\plugins\HealersHelper\
Keep your existing healers-helper.json settings file.

=== DUNGEON HELPER 5 BETA (5.0.x / VoK.Sdk 5.3.0, .NET 10 x64 In-Process ImGui) ===
1. Close DDO. Open Dungeon Helper 5 Beta -> Plugins -> Install from zip.
2. Select HealersHelper-X.Y.Z-dh5-plugin.zip (Authenticode + community entitlement signed; archive root files).
3. Enable "Healers Helper" and launch DDO (DX10 or DX11 required).
4. Manual fallback folder: %LocalAppData%\DungeonHelperData\plugins\Healers Helper\

USE
- DH 4: Open the DDO Healer's Helper panel in DH. Both the center banner and compact
  status HUD render as independent click-through layered windows with
  WDA_EXCLUDEFROMCAPTURE (0x11) and Wine/Proton guards (IsWineRuntime).
  Test Preview Banner with Lossless Scaling (WGC and DXGI) with the panel closed.
- DH 5 Beta: Click the toolbar icon (or configure via /hh commands in DDO chat).
  HUDs draw natively inside DDO's DX10/11 frame via ImGuiNET with zero external
  overlay HWND. Configure optional Quick-Heal / Quick-Raise hotbar slots (0 = Disabled)
  for targetless InvokeHotbar casting without dropping your Boss/Tank target.
- Default Hotkeys: Ctrl+Shift+K ON/OFF, Ctrl+Shift+H Focus, Ctrl+Shift+J Mode,
  Ctrl+Shift+T Target Critical. Optional hotkeys: Toggle Banner, Quick-Cast Critical,
  Reset Saved, Copy Scorecard.
- 3 Shared Themes (Settings -> Theme or /hh theme <eberron|cannith|feywild>):
  Eberron Obsidian & Gold (default), House Cannith Arcane Forge, Feywild Eldritch Twilight.
