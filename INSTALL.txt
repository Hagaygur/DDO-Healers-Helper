DDO HEALER'S HELPER 1.0.0

INSTALL HealersHelper-1.0.0-plugin.zip DIRECTLY. It contains only three runtime files.
HealersHelper-1.0.0-source.zip is separate; do NOT import it into Dungeon Helper.

1. Close DDO. Open Dungeon Helper Settings > Add plugin from zip file.
2. Select HealersHelper-1.0.0-plugin.zip.
3. If asked to overwrite the already-installed HealersHelper folder, choose Yes.
4. Fully exit Dungeon Helper from its tray icon, restart it, then launch DDO.

If DH refuses the update or reports a file in use:
Fully close DDO and Dungeon Helper. Extract the ZIP. Copy the CONTENTS of
plugins\HealersHelper into your existing installation's plugins\HealersHelper
folder, replacing files. Usually this is:
%APPDATA%\Dungeon Helper\plugins\HealersHelper\
Do not copy the DLL into a second plugin folder. Keep settings/logs.

USE
Open the DDO Healer's Helper panel in Dungeon Helper.
Configure Mode (Party, Single Player, Off), Threshold %, Dead Alert seconds,
Banner font size (18-140 px, default 56), Status font size (9-48 px, default 14),
Flash interval (100-1000 ms, default 250), and Auto-Target / Hotkeys (default
Ctrl+Shift+K ON/OFF, Ctrl+Shift+H Focus, Ctrl+Shift+J Mode, Ctrl+Shift+T Target Critical).

Click Preview Banner, then Move Banner / Move Status (20s) to drag each HUD to
your preferred monitor-relative position. Close the DH control panel while
playing; the separate transparent click-through HUDs stay active.
Enable Lossless Scaling and test Preview Banner in both WGC and DXGI.

The status should say Capture exclusion: ON. This means Windows accepted the
WDA_EXCLUDEFROMCAPTURE setting; it is not proof that every LS capture backend
honors it. Live DDO and LS testing is still required.
