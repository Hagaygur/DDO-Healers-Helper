## Key invariants

- **Portable vs host-specific split:** Shared files under `src/` (`Contracts.cs`, `UiThemePalette.cs`, `Settings.cs`, `OfflineSettingsEngineView.cs`, `HotkeyMatcher.cs`, `HealerStats.cs`, `PeopleSavedTracker.cs`, `TargetRestoreTracker.cs`, `HealerState.cs`, `BannerPresentation.cs`, `StatusHudPresentation.cs`) must never reference WinForms, `System.Media`, `VoK.Sdk`, or Win32 P/Invoke. `src-dh5/` must never reference `System.Windows.Forms` or `System.Media`.
- **Zero-deadlock DH 5 async rule:** Run `TickAsync()` on a non-reentrant ThreadPool timer; never block `ClientFrameStep()`, `ImGui_Render()`, or `lock` on frame-marshaled SDK tasks.
- **ImGui stack safety:** Every `ImGui.Begin`/`BeginChild`/`BeginTabBar`/`BeginTabItem` pairs unconditionally with its `End*` call, and every `PushStyleColor`/`PushStyleVar`/`PushFont`/`PushID` balances across all branches and themes.
